# Inference-time intervention on attention head contributions

We investigate a direction applied to selected attention heads at inference time. To avoid confusing the post-projection residual with concatenated heads, the input direction bank D has shape [2,width]: each row is an already output-projected head direction (W_o,h d_h). Intervene on the attention branch at layer 1, adding alpha*sum(D,dim=0) to its contribution before residual addition. Thus z=x+y+alpha*sum_h D_h. No optimization, request state, replay or external actions. All prefill and decode rows participate.

Deliver `Workload(alpha=0.6)` with imported instance state `heads`, FP32 field `directions` [2,width], and attention-site custom residual method `intervene(x,y,directions)` at layer 1, bound to that field. Preserve x.dtype. Acceptance checks independent non-collinear head directions, zero alpha, shapes, layer and attention site. An unprojected reshape of y is incorrect: y is after W_o.
