# Decoding by contrasting layers

We study training-free decoding that selects an early layer whose distribution differs most from the mature layer. For early candidates 0 and 1 and mature layer -1, compute p=softmax(logits), m=(p_final+p_early)/2, and JSD = (KL(p_final||m)+KL(p_early||m))/2. Select the largest JSD independently per row (first on ties). The desired sampler logits are log(p_final)-log(p_chosen); exclude tokens with p_final < tau*max(p_final). No state, training, host actions or replay. Run on decode rows before sampling.

Deliver `Workload(tau=0.1)` with an add-logits method `contrast(logits)`, bound to layer_logits((0,1,-1)); logits has shape [rows,3,vocab]. Return an additive delta, accounting for the mature raw logits already in the sampler. Acceptance compares the resulting sampler logits, -inf mask, rowwise choice, and declaration.
