# Adaptive looped decoder depth with early exit

We examine bounded depth reuse: run the first layer once, then reuse the remaining layers up to three passes for each decode token. Start h=layers(0,1)[0]. For each pass, active rows satisfy mean(h^2)>0.4 and have never exited before. Call the remaining slice layers(1,hidden=h,active=mask), taking [-1]; inactive rows keep their previous hidden and cannot reactivate. All slice calls use ordinary KV commit semantics. Finish after three passes; prefill remains native. No state, trainable parameters, host actions or replay outside this forward.

Deliver `Workload(threshold=0.4)` with `forward(layers)` decorated custom_forward(tokens="decode"). Use active= rather than a Python tensor-valued if. Acceptance uses a deterministic fake decoder to compare mixed/all/none exit cases and invocation masks, then pllm.testing.check for native program tracing, never-exit, row compaction and KV contracts. The threshold is constructor-configurable.
