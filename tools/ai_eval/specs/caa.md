# Contrastive activation addition

We investigate a small steering intervention learned from paired positive and negative activations. A shared vector d = mean(H+) - mean(H-) shifts the residual stream at layer 1 by alpha*d, leaving all other model computation intact. This tests whether a paper-level intervention can be expressed without an engine wrapper. No training, external actions, replay, or request state is needed. Apply to prefill and decode, before the next sublayer consumes the stream.

Deliver `direction(positive, negative)` (ordinary tensor function, inputs [examples,width]) and `Workload(alpha=0.7)`. Declare imported instance state `steer` with FP32 field `vector` [width], and a layer-1 custom residual on the MLP site. Its method `intervene(x,y,vector)` returns x+y+alpha*vector, preserving x.dtype; x/y are [rows,width]. The vector is supplied through pllm's state input, not saved in Python. A zero alpha must reproduce x+y. Acceptance compares paired means, intervention arithmetic, the model-site declaration, and neutral behavior.
