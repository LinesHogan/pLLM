# Decode-time self-distillation with a low-rank predictor

We examine an ESamp-like online student trained independently for each request. Predict the mature hidden state t at layer 2 from x at layer 0 using f(x)=x A^T B^T, rank 2. Per-row loss is mean_d (f(x)-stopgrad(t))^2. Only decode rows train, after sampling, one AdamW step at learning rate 0.01, betas=(0.9,0.999), eps=1e-8, with per-state mean reduction and no decay. Both factors initialize deterministically: A is all 0.05, B zero. Before sampling, guide with f(x), beta 0.5. Updates from step n become readable at n+1 (publish lag 0). No gradients through base model/KV, replay or host actions.

Deliver `Workload()` with RequestState `student` fields a [2,d], b [d,2], a framework AdamW optimizer, `predict(x,a,b)` as guide_sampling, and `loss(x,target,a,b)` as train. Request-bound parameters have leading rows axes. Return row losses [rows]. Acceptance compares predictions, row losses, both parameter gradients, one optimizer update, request state and decode/phase declarations.
