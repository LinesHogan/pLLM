# A test-time-trained memory beside the MLP

We augment layer 1 with a request-local fast weight matrix M, initially zero. For each chunk of 2 tokens, normalize residual rows k=x/max(||x||_2,1e-12), read r=k M^T, output z=x+y+0.5r, and update M'=M-0.3/n*(r-y)^T k for n rows. Every row reads the matrix from the start of its chunk. The framework owns incomplete chunks and request isolation across arbitrary prefill/decode splits. There is no optimizer, host action or replay. Read and update on both prefill and decode.

Deliver `Workload()` with a single-field FP32 RequestState `memory` (`M` [d,d]), and stateful mlp-site custom_residual at layer 1 with chunk=2. Method `remember(x,y,M)` returns (stream,next_M), preserves x.dtype for stream, computes memory math in FP32, and does not mutate inputs. Acceptance compares nonzero memory reads, updates, gradients of the mathematical loss, and chunk/state declaration. Explain/check may explicitly skip native model-site execution.
